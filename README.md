# ✦ HabitFlow — трекер привычек

Интерактивный трекер привычек с геймификацией: уровни, ранги, опыт (XP), серии и анимации.
Одностраничное веб-приложение на **HTML + Tailwind CSS + JavaScript** без сборки и бэкенда.

## Возможности

- **Привычки по категориям:** здоровье, продуктивность, спорт, обучение, осознанность.
- **Отметка дней кликом:** вид на неделю или на месяц, листание периодов.
- **Профиль игрока:** аватар (меняется по клику), редактируемое имя, уровень, ранг и полоса опыта.
  За каждую отметку начисляется 10 XP.
- **Ранги:** 🌱 Новичок → 📘 Ученик → ⚔️ Практик → 🏅 Мастер → 🔮 Гуру → 👑 Легенда.
- **Статистика:** кольцо прогресса за сегодня, график за 7 дней, текущая и лучшая серия.
- **Эффекты:** конфетти при отметке, всплывающий «+10 XP», пульсация ячеек, окно нового уровня,
  glassmorphism, подсветка карточек под курсором, наклон профиля, анимированный фон.
- **Светлая и тёмная тема** (по умолчанию как в системе).
- **Сохранение в `localStorage`:** данные не пропадают после перезагрузки.
- **Адаптивная вёрстка** и поддержка настройки «уменьшить движение».

## Запуск

Откройте `index.html` в браузере. Нужен интернет: Tailwind, шрифт и конфетти загружаются с CDN.

В VS Code удобнее через расширение **Live Server**: правый клик по `index.html` → *Open with Live Server*.

## Структура

```
index.html   — разметка
style.css    — стили, анимации, glassmorphism
app.js       — логика: состояние, XP и уровни, рендер, эффекты
```

## Публикация на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → выбрать ветку и папку `/ (root)`.
